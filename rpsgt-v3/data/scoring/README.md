# Scoring Lab data

All Scoring Lab visual packs in this folder are original Sleep Pathways Guild teaching schematics. They are not patient recordings and do not reproduce proprietary AASM scoring-manual figures or tables.

## Phase 3 mini-study

`mini-study.json` defines a scored sequence of 12 consecutive 30-second staging decisions with three interleaved full-montage context stops. The context stops reuse original app-authored cases from `context-cases.json` for arousal, limb-movement, and respiratory-boundary reasoning.

The Phase 3 mini-study has its own pass/attempt history and remains separate from the locked Scoring Lab completion gate. First submitted responses determine the score; incorrect responses must still be corrected before progression. Real scoring requires the current official AASM Scoring Manual, the complete recording, facility procedures, and supervised scorer training.
