# PAP guided-station content boundary

The learner activities in this folder are original Sleep Pathways Guild educational material for sleep-technologist practice. They intentionally teach protocol-first reasoning rather than a fixed titration recipe.

Do not add dated numerical pressure-change rules, proprietary AASM tables/manual text, vendor screenshots, or patient recordings to this guided station pack. When clinical practice requires a therapy change, the learner-facing lab should point back to the current order, current professional guidance, manufacturer instructions, facility policy, and supervised competency.

Learner-facing references must remain APA style only.
